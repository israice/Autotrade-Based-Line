
создай python скрипт

скрипт проверяет значение в файле
CORE/DATA/C_temp_config.yaml
LARGE_OPEN_STATUS: RED


если значение GREEN то запускает 
CORE/BACKEND/F_CHECK_HIGH_LOW_LINE/A_high/A_run.py


если значение RED то запускает 
CORE/BACKEND/F_CHECK_HIGH_LOW_LINE/B_low/B_run.py



все настройки переменных и путей должны быть только в верхней части кода


выводи в косноль сообщения из запущенных скриптов
не выводятся пустые строки в консоль

отоброжай замер времени выполнения скрипта СПИСКА в консоли

все пути указаны от корня проекта там где находится файл .env

в консоли при выводе сообщений не должны выводиться пустые строки
