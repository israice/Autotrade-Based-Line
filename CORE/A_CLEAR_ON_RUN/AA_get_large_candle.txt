
создай python скрипт

в файле settings.yaml 
находится переменные 
symbol: XRPUSDT 
timeframe_interval: 3m 
candles_limit: 2

скрипт делает запрос на binance 
получая данные perpetual futures 
используя public API

полученные свечи надо записать в файл
CORE/B_GET_DATA/BA_get_large_candle.yaml

это точный порядок записи 
- candle_0_close_time: '2025-07-17 00:28:59'
  candle_0_update_time: '2025-07-17 00:28:25'
  candle_0_open_time: '2025-07-17 00:28:00'
  candle_0_open: '3.0617'
  candle_0_high: '3.0617'
  candle_0_low: '3.0598'
  candle_0_close: '3.0599'
- candle_1_close_time: '2025-07-17 00:27:59'
  candle_1_update_time: '2025-07-17 00:28:25'
  candle_1_open_time: '2025-07-17 00:27:00'
  candle_1_open: '3.0671'
  candle_1_high: '3.0674'
  candle_1_low: '3.0617'
  candle_1_close: '3.0617'


candle_0 это текущая свеча
candle_1 это предыдущая свеча
и так далее если указано более двух свечей в candles_limit

все пути указаны от корня проекта там где находится файл .env
пути используй с прямыми слэшами 

сделай максимально универсально с поддержкой всех интервалов

перечеслкение настроек только исключительно вверху скрипта 
включая пути и названия переменных и параметры
в самой логике используются только переменные из настроек 
только после перечесления всех настроек должна начинаться логика 
используя только переменные из настроек 

в консоле отоброжай результат в одной строке включая время выполнения скрипта
текущее время
print(f"- - B - - << {limit} >> candles << {interval} >> timeframe for << {symbol} >> at {current_time}")
