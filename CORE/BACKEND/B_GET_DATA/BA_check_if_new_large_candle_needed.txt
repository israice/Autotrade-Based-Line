
создай python скрипт

который делает проверку и если проверка пройдена запускает список скриптов по очереди 

если в файле 
CORE/DATA/A_small_new_candles_data.yaml
candle_0_close_time: '2025-07-20 23:58:01'
выше чем дата и время в 
CORE/DATA/B_large_new_candles_data.yaml
candle_0_close_time: '2025-07-19 23:57:00'

то запускай по очереди скрипты из СПИСКА
SCRIPTS = [
    'CORE/BACKEND/B_GET_DATA/BCA_get_large_candles.py',
]

если значения при сровнении ровны то ничего не делает

все пути указаны от корня проекта там где находится файл .env

выводи в косноль сообщения из запущенных скриптов
убедись что не выводятся пустые строки в консоль

отоброжай замер времени выполнения скрипта СПИСКА в консоли
