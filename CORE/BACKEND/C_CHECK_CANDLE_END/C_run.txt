
создай python скрипт

в файле 
CORE/DATA/B_large_new_candles_data.yaml
candle_0_open_time: '2025-07-18 09:38:59'

в файле 
CORE/DATA/F_large_old_candles_data.yaml
candle_0_open_time: '2025-07-19 09:39:59'

скрипт сравнивает значения 

если значения не совпадают и значение не null то запускает скрипты по очереди

SCRIPTS_LARGE = [
    'CORE/BACKEND/C_CHECK_CANDLE_END/A_large/A_run_large.py',
]

если значения совпадают то 
скрипт значения из других файлов 
из файла 
CORE/DATA/A_small_new_candles_data.yaml
candle_0_open_time: '2025-07-19 09:39:59'
и файла
CORE/DATA/E_small_old_candles_data.yaml
candle_0_open_time: '2025-07-19 09:39:59'

если значения не совпадают и значение не null то запускает скрипты по очереди

SCRIPTS_SMALL = [
    'CORE/BACKEND/C_CHECK_CANDLE_END/B_small/B_run_small.py',
]

если значения совпадают то ничего не надо делать дальше
и
если был запущен A_run_large.py
то запускать B_run_small.py не надо это важно
надо запускать или A_run_large или B_run_small
но не то и то 

выводи в консоль сообщения из запущенных скриптов
убедись что не выводятся пустые строки в консоль

отоброжай замер времени выполнения скрипта СПИСКА в консоли

все пути указаны от корня проекта там где находится файл .env

пути используй с прямые слэши

все настройки вверху
функции в низу
в настройках должны быть так же все названия переменных 
к которым мы обращаемся
