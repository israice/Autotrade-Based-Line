
создай python скрипт

в файле 
CORE/DATA/C_temp_config.yaml
PERCENTAGE_CHANGE_LARGE: 0.138
значения могут быть как положительными так и отрицательными

если 
NEXT_LONG_PERCENT: 0.139
меньше чем 
PERCENTAGE_CHANGE_LARGE: 0.138
то запускает по очереди список скриптов
CORE/BACKEND/D_CHECK_SELL_PERCENT/A_long/A_run.py
если больше то не запускает

если значение отрицательное как в примере ниже
PERCENTAGE_CHANGE_LARGE: -0.138
то надо сверять с 
NEXT_SHORT_PERCENT: -0.139
если 
PERCENTAGE_CHANGE_LARGE выше (отрицательно) чем 
NEXT_SHORT_PERCENT 
то запускает по очереди список скриптов
CORE/BACKEND/D_CHECK_SELL_PERCENT/A_short/B_run.py
если ниже то не запускает

например 
PERCENTAGE_CHANGE_LARGE: -0.020
значение не ниже чем 
NEXT_SHORT_PERCENT: -0.070
значит не надо запускать скрипты 
а если бы было ниже тогда да запускать



все настройки должны быть только в верху скрипта 
включая названия переменных для конфигурации перед запуском 
а применения в коде ниже

выводи в косноль сообщения из запущенных скриптов

отоброжай замер времени выполнения скрипта СПИСКА в консоли
если скрипт не запускается то выводи ошибку

все пути указаны от корня проекта там где находится файл .env

не создавай переменные по умолчанию
если переменная отсутствует в файле выводи ошибку

если одно из переменных не имеется то выводи сообщение об ошибке
не создовай переменные по умолчанию 

выводи сообщения из запущенных скриптов
в консоли не должно быть пустых строк !
