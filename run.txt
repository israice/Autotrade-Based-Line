
создай python скрипт

Вместо запуска скриптов через 
subprocess
выполняйте их код напрямую с помощью 
exec().
Для этого захватывайте вывод с помощью 
contextlib.redirect_stdout 
и 
io.StringIO

запускает список скриптов по очереди 
SCRIPTS = [
    "CORE/TOOLS/msg/ping.py",
    "CORE/TOOLS/msg/pong.py",
]

отоброжай замер в консоли замер времени выполнения СПИСКА

не создовай дефолтные значения в коде
выводи ошибку если значение не найдено в указоном файле

все пути указаны от корня проекта там где находится файл .env
все пути с прямыми слэшами


все возможные настройки в скрипте должны быть только в верху 
ввиде ключ значение 
пути тоже в верху
