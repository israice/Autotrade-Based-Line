
создай python скрипт

в файле 
CORE/B_GET_DATA/BA_get_large_candle.yaml
  candle_0_open: '2.9486'

в файле 
CORE/Y_COPY_DATA/YA_clone_candles.yaml
  candle_0_open: '2.9486'

если значение равны или null то ничего не надо делать дальше

если значение из 
CORE/B_GET_DATA/BA_get_large_candle.yaml 
выше значения из 
CORE/Y_COPY_DATA/YA_clone_candles.yaml
то запускает скрипты по очереди

SCRIPTS_HIGH = [
    'CORE/C_CHECK_CANDLE_END/CA_message_up.py',
    'CORE/C_CHECK_CANDLE_END/CA_mess2age_up.py',
]


если значение из 
CORE/B_GET_DATA/BA_get_large_candle.yaml 
ниже значения из 
CORE/Y_COPY_DATA/YA_clone_candles.yaml
то запускает скрипты по очереди

SCRIPTS_LOW = [
    'CORE/C_CHECK_CANDLE_END/CB_message_down.py',
    'CORE/C_CHECK_CANDLE_END/CB_messa2ge_down.py',
]





все пути указаны от корня проекта там где находится файл .env

выводи в консоль сообщения из запущенных скриптов
убедись что не выводятся пустые строки в консоль

отоброжай замер времени выполнения скрипта СПИСКА в консоли


пути используй с прямые слэши

все настройки вверху
функции в низу
в настройках должны быть так же все названия переменных 
к которым мы обращаемся
